# 03-01 — Dubplates metadata, interest and downloads

## Frontend thinking gate

Finished artist/developer site; existing unlisted listening library and separate dark content admin. Friends/producers arrive by shared link, find/play/select tracks and export. Owner uploads/edits music and needs to compare interest. Keep existing rows, waveform, sticky filters and player; extend native React/CSS controls, no UI-framework change. Primary information remains title/artist/playback, then production stage/EP/BPM/LUFS and bottom genre/tag chips. Internal rating and all analytics must never appear in public payload/UI. Unknown legacy rating/stage/loudness remains unknown, not guessed. No producer identification, IP or fingerprint storage.

Recovery: existing retry, safe audio replacement, publication checks, drafts/session expiry. Desktop and mobile320/390 must remain usable. Native labeled controls and dialog focus per UI/UX/accessibility skills. Integrated whole-file loudness uses original channels/audio and EBU R128; measurement must never normalize/replace existing audio. Baseline21tracks/22assets,1.3GB in persistent store. Writes only C:/Projects/Muvs, never OneDrive; production catalog/audio preserved, unrelated dirty /root/muvs checkout untouched.

## QA inventory / signoff

- Public: multiple black chips below each row; search/tag/stage/reset; finite LUFS-I including zero; old unknown values absent; no rating/statistics/private identifiers.
- Export: zero selection disabled, one ZIP default/file choice, multiple ZIP only, MP3/WAV availability, cancellation/Escape/focus, real download filenames and archive entries, duplicate titles collision-safe, error/retry.
- Interest: real playback qualifies, seek jump/pause/wait never creates listens; repeated play deduped; successful full download counts, failed/HEAD/preview/ticket creation/reuse do not. Owner excluded. Persistence across restart, rate bounds, admin authentication/origin safeguards.
- Admin: rating0 and10 and unset, invalid bounds blocked; comma-separated multiple tags saved/recovered, stageunknown preserved; upload measured; legacy loudness queue/status; statistics empty/loading/error/retry, sortedtrack data and format/recent details.
- Failure/data safety: original audio never rewritten, no inferred existing ratings/stages, no lost21tracks/22assets, no generalized CMS changes, no server config or unrelated applications changed.

Measurement references: official FFmpeg scanner https://ffmpeg.org/ffmpeg-filters.html#ebur128-1 and implementation https://github.com/FFmpeg/FFmpeg/blob/master/libavfilter/f_ebur128.c (whole-file integrated loudness). Initial loudnorm null-output implementation replaced by direct scanner after confirming unnecessary normalization/oversampling cost and a buffered-tail measurement difference on dynamic short clips. This is a task1 performance/correctness refinement, not an architecture change.
