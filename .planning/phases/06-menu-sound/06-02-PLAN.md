# 06-02 — Configurable hub caption color

## Objective / tiny UX gate

Change only the floor captions beneath the four main 3D menu objects to
white by default, then honor the user's follow-up: add a saved admin color
setting in Visual style. Preserve Code project descriptions, fonts, layout,
motion, content and all other saved presets. A restrained text shadow keeps
white lettering distinguishable on the pale floor without changing the gradient.

Surface: finished artist-site 3D hub. Task: choose Music / Mixes / Code /
About. Admin task: choose a native color or enter HEX, preview, save, then
refresh the site. Invalid values stay in the form with an associated error;
save failure must not claim success. Risks: recoloring shared Code descriptions,
unsafe CSS values, stale/default overwrites, or low-contrast chosen colors.

## Tasks

1. Add strict canonical HEX normalization/validation, the existing confirmed
   effects-patch save flow, native color/HEX controls and preview, and scoped
   inherited CSS variable. Check mobile / small mobile / desktop, all four
   items, custom color, dive/return and unchanged Code descriptions. Run
   tests/build/review plus real isolated API save/restart and admin error/retry.
2. Publish through the existing guarded deploy, verify exact live CSS and
   content invariance, and record outcome. No CMS or settings writes.
