# 06-03 — Matching Code object captions

## Objective / tiny UX gate

Make short descriptions below all five Code objects white with the same
restrained shadow as the main menu. Reuse the existing saved caption color
so owner-selected color stays consistent; white is the default. Update
the existing admin help to disclose the extended scope. No schema change,
new control, layout/font/animation/content change or production data write.

Surface: finished artist/portfolio 3D Code section. Task: browse project
cards and read their short descriptions. Risks: accidentally recoloring
headings/long descriptions, poor pale-floor contrast, clipping or changed
caption placement. Preserve existing geometry, rich-text inheritance and
navigation.

1. Apply the scoped color/shadow and help correction. Verify all five
   cards with native mobile navigation, 320/390/1440 screenshots, direct
   route and hub entry/return, white/default and a staged custom color.
