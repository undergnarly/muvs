# 01-01: Dubplates

## Objective
Ship an unlisted track library and its admin workflow without changing public music content.

## Context
React 19 / Vite, existing Urbanist typography, grayscale gradient, lime accent. Express 5 on localhost:3001 behind nginx. Cookie-authenticated admin. Persistent data outside atomic release directories.

## Tasks
1. Implement isolated validated catalog/audio/export API and backend tests. Commit `feat(01-01): add secure dubplates media API`.
2. Build library, one-player waveform interaction, filters/selection/format export and admin upload/editor. Commit `feat(01-01): add dubplates library and admin`.
3. Verify real audio ingestion/download, browser desktop/mobile states, noindex and unchanged public routes; deploy with narrowly scoped nginx additions. Commit integration fixes separately as needed.

## Success criteria
Published tracks playable/seekable and selectable; search/filters/sort work; exports contain selected files in real formats; drafts inaccessible publicly; admin errors preserve edits; route unlisted/noindex; empty library is honest (no invented tracks); works at 390px and 1440px; originals survive deployments.
