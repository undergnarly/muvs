# 02-08 — Paint-stroke loading stamp

## Objective

Replace the white startup progress line with the user's acid-lime hand-painted trace, revealed left to right behind the existing black MUVS tag. Publish and verify real cold startup, completion and recovery without delaying the render-first reveal.

## Tiny UX / design gate

- Surface: finished expressive artist portfolio, initial loading overlay.
- Journey: open the URL → recognize MUVS / see loading activity → enter the real sound system and navigation. No new decision or control before load completion.
- Impact: one focal artwork, inline rough vector paint in brand #CCFF00 and the existing logo alpha rendered black. Existing gray-to-white background and restrained status remain.
- Recovery: preserve 18s early bundle watchdog / Reload and 15s scene recovery. Respect reduced motion. No artificial minimum splash duration, infinite shimmer, layout animation or external dependencies for the loading graphic.
- Reference: user marker/spray swatch behind the handwritten tag. Hand-cut contour and dry-brush flecks, not a straight progress rectangle or decorative glow.
