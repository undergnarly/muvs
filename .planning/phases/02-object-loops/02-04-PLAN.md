# 02-04 — Reliable cold start and restrained motion

## Objective
Never reveal an empty or white artwork plane while menu media loads. Warm all three menu videos/masks and exact first-frame posters during the splash; preserve a bundled still on every failure. Remove Music drop/dust, Mixes entrance gain/fade and Code lid opening. Use a one-second initial20% scene zoom-out, periodic restrained bronze glints, and unchanged Code blue-white face light.

## UX gate
Finished artist portfolio, expressive3D menu. Visitors arrive at the homepage, choose Music/Mixes/Code/About and swipe or enter a section. Existing labels, geometry, CMS and navigation remain the design reference. First decision must never depend on media finishing. Desktop/mobile success: an artwork still is present at reveal and every switch; slow/error/reduced-motion recover to the same still. No new controls or technical status vocabulary. Keep Three/R3F, no library migration. User-requested1s decorative zoom is separate from interaction response.

## Tasks
1. Prepare exact decoded-first-frame posters, bundled thumbnail fallback and a fixed-geometry Mixes glint every3s; retain stronger Code light.
2. Replace per-object entrances with stable material selection, shared paused menu warmup and actual scene-ready splash gate. Add initial-only, interruptible1s camera zoom-out.
3. Test actual cache-disabled startup, throttled/failed video+poster+mask, rapid switching and reduced motion. Inspect first-frame screenshots at100ms intervals, desktop/mobile, then atomic publish and live checks.
