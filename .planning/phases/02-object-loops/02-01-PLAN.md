## Tasks
1. Produce and visually review four source loops, stabilize/trim only where needed, preserve static silhouettes/alpha and encode compact web media. Reject composition changes or visible loop seams.
2. Integrate an exact-poster sidecar manifest and shared, lazy, visibility-controlled VideoTexture with correct color/alpha and original-image fallback. Respect reduced motion/data saving and offer a pause control. Preserve navigation, camera and gyro removal.
3. Verify seams, desktop/mobile navigation, hidden-tab/offscreen pause, fallback/error and reduced-motion behavior; build/test, deploy via existing atomic release, verify live assets and report credits spent.

## Success criteria
- Four reviewed subtle loops, at most one visible artwork video playing; original posters before ready or if playback fails.
- No rectangular backgrounds, static geometry unchanged, no camera drift, no audio, no sensor subscriptions.
