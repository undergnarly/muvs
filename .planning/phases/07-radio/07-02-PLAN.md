# 07-02 — Radio surface and route

## Objective / context

Implement the approved Radio journey in the existing React/Three scene. See
07-01 for the visual gate, palette, artwork and preservation constraints.

## Tasks

1. Shared immutable era data, main `/radio` 3D objects with horizontal native
   controls, direct era links and centered menu return. One camera stop only.
   Clearly unavailable Play / Coming soon; no stream or fake playback state.
2. Header navigation, public document/SEO route, sitemap/reserved slug and
   optional admin caption field. No production CMS or settings write.

## Success criteria

All three era links resolve and select correctly; native swipe/arrow/keyboard
can reach them, first/last bounds are truthful. No accidental AlbumPlayer or TV,
new audio request, diagonal return or inherited release-specific camera preset.
Shared server/client metadata is truthful and private pages remain unlisted.
