# 07-05 — Owner-adjustable Radio shadow placement

## Frontend thinking gate

Finished artist site; owner-only admin settings surface. The owner enters
Admin → Radio, chooses main-menu receiver or an era, adjusts its shadow and
explicitly saves. First decision is which receiver to tune. Prioritize object
identity, inheritance, three precise controls, then save feedback. Use existing
dark admin/native controls, Russian plain labels and the current React router.
No UI kit, stream editor, fake preview, JSON or new public navigation. Mobile
primary action is saving; failed saves retain drafts and offer retry. Preserve
the public site’s visual identity and all content. Accessible labels, keyboard
focus and field-linked errors are mandatory.

## QA inventory / success criteria

- Bridge absent; original single-quad shadow/floor/alpha rendering restored.
  Distant art retains textures (ArtworkMaterial fog=false).
- Four independently selectable profiles: menu, Roots, Y2K, New Era. Default
  inherits current global settings; custom initialization has no jump.
- Length changes cast only; X translates only shadow left/right; depth moves
  closer/farther along floor. Other objects and global effects unchanged.
- Target switching preserves unsaved values; custom inheritance toggle, valid
  save/reload, invalid number/focus, network failure/retry and initial-load
  failure all work truthfully. No successful message on failed persistence.
- 320/390 phone and 1440 desktop screenshots: labels, native fields, help,
  selected receiver, save/status readable with no horizontal clipping. Admin
  is intentionally scrollable; public Radio/footer remains fixed and fits.
- Isolated actual API: auth/origin, bounds/key validation, restart persistence,
  interleaved distinct-target saves and unrelated branch preservation.
- Public menu + three eras: default legacy look, positive/negative X/depth,
  different lengths, native arrows/return/reentry, fallback and reduced motion.
- Production: guarded release, exact changed public bundle hashes, runtime
  health; public CMS/private DB/catalog/analytics unchanged. No production
  test saves, plays or downloads. No physical-handset claim.

Receiver redesign is paused pending the owner's reply; no new generation yet.
